СБОРКА APK ЧЕРЕЗ GITHUB ACTIONS

1. Создайте на GitHub новый репозиторий с именем PressureDiary.
2. Загрузите в него ВСЕ файлы и папки из этой папки проекта (включая скрытую папку .github).
3. После загрузки откройте вкладку Actions и выберите Build Android APK.
4. Дождитесь завершения сборки со статусом Success.
5. Откройте выполненную сборку и скачайте artifact PressureDiary-debug-apk.
6. Распакуйте скачанный ZIP: внутри будет app-debug.apk.

Сборка выполняется на серверах GitHub; Android Studio на вашем ПК не нужна.
